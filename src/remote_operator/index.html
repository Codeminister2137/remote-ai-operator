Judge quick start — 3 steps

Scripted or Meta? Scripted offline reference runs a fixed pre-written demo: no AI, no cost, no key needed. Meta mode runs real AI coding, charged to your own Meta account — it needs your key attached below.

  1. Connect: enter the demo access code in Access, register your judge account and log in, then set spending limits (Max requests + Approved USD) and attach your Meta API key in “Your model key”. The wizard below tracks each step.
  2. Build: open the Build view and follow its steps — request, review, try the feature. Everything happens in order on one screen.
  3. Supervise: for longer work, open the Supervise view: create a thread, chat, write the plan, check run settings, approve the plan, then review each run.
